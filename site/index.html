macOS 14+ · Menu bar · MIT

Stop fighting the input source switcher.

macOS won't let you remove ABC, so it can switch on you at the worst moment. Keyboard Source Locker snaps the active input source back to the one you chose — after a short 200 ms debounce.

Download for macOS View source

Lock any input source

Pick a target from the menu bar — for example 微信输入法 — and turn the lock on.

200 ms debounce

Rapid switches cancel each other, so only the settled source triggers a restore.

Menu bar only

No Dock icon, no windows. Launch at login is one click away.

Install

  1. Download the latest Release zip.
  2. Unzip and move KeyboardSourceLocker.app to /Applications.
  3. Launch it — look for the lock icon in the menu bar.

First launch may need System Settings → Privacy & Security → Open Anyway.
