# Contributing

Thanks for helping improve Keyboard Source Locker.

## Development

Requires macOS 14+, Swift 6.2+, Node.js 18+, and pnpm (see `packageManager` in `package.json`).

```bash
pnpm install
vp run test
vp run build
vp run package
```

Tasks are defined under `run.tasks` in `vite.config.ts` ([Vite+](https://viteplus.dev)). Prefer [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `chore:`, …). GitHub Release notes are generated by [`changelogithub`](https://github.com/antfu/changelogithub).

## Releasing

```bash
pnpm install
pnpm run release   # bumpp → commit, tag vX.Y.Z, push
```

CI then: test → package (from `package.json`) → **changelogithub** → upload assets → GHCR. The git tag must match `package.json` version.
