# Contributing

Thanks for helping improve Keyboard Source Locker.

## Development

Requires macOS 14+, Swift 6.2+, and Node.js 18+.

```bash
npm run test
npm run build
npm run package
```

Prefer [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `chore:`, …). GitHub Release notes are generated by [`changelogithub`](https://github.com/antfu/changelogithub).

## Releasing

```bash
npm i
npm run release   # bumpp → commit, tag vX.Y.Z, push
```

CI then: test → package (from `package.json`) → **changelogithub** → upload assets → GHCR. The git tag must match `package.json` version.
