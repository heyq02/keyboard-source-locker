# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` / latest release | ✅ |
| Older tags | ❌ Best-effort only |

## Reporting a vulnerability

Do **not** open a public issue. Contact [@heyq02](https://github.com/heyq02) privately with impact and reproduction steps. Expect an initial response within 7 days.
